# 第2話ケーススタディ

## 題材

「ゲームはパッケージ版で所有するべきか、ダウンロード版やサブスクリプションで遊ぶべきか」

風刺対象は、自分の購入方法だけが賢いと思い込み、生活環境や遊び方の違いを無視する心理。

## シナリオ構造

- 部長: 現物、棚、ケース、説明書を含む所有の楽しさを主張。ただし棚は限界
- レン: DLとサブスクの便利さを主張。ただし限定版と店舗特典を収集
- チカ: 本、電子書籍、図書室の使い分けに例え、買い方より実際に遊ぶことを指摘
- 因果応報: レンが予約した限定版が部室へ届く
- タグ: チカの家の倉庫を聞いた部長とレンが初めて完全一致

## 4枚のイベントスチル

| ID | 使用scene | 役割 |
|---|---|---|
| `ep02_001` | `ep02_05_limited_choice` | 部長が大型限定パッケージを提示する題材スチル |
| `ep02_002` | `ep02_16_delivery_door` | レンの予約限定版が届く因果応報 |
| `ep02_004` | `ep02_17_box_crisis` | 満杯の棚へ入らずチカが止める物理的クライマックス |
| `ep02_003` | `ep02_23_tag_punch` | チカ宅の倉庫案で部長とレンが完全一致するタグ |

4枚とも分岐合流後を含む全ルート共通経路へ置いた。

## 画像処理

- 最終解像度: 224×136
- 比率: 28:17
- 形式: 4bit indexed PNG
- 表示色: 15色以内
- index 0: 予約枠として未使用
- ディザ: なし
- RGB: PCE相当の3bit段階へ丸め
- 輪郭: 太く、縮小後も顔とポーズが読めることを優先

## スクリプト組み込み

イベントスチルsceneの冒頭で、部長、チカ、レンのslotを`visible: false`にし、その後にスチルを通常backgroundとして`x:2, y:1`で表示した。次の通常会話sceneでは背景と立ち絵を改めて表示した。
