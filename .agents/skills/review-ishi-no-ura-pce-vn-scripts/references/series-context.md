# 「いしのうらにいる！？」レビュー用シリーズ文脈

## 正本の優先順位

1. 対象話の assets/pce-vn-scenes.json
2. 対象話の assets/pce-assets.json
3. 現行 series-bible.md と natural-dialogue-guidelines.md
4. この要約

この要約と対象JSONが食い違う場合は、矛盾として報告し、黙って要約側へ合わせない。

## 作品

- 正式タイトル: 「いしのうらにいる！？」
- ジャンル: 女子部活日常コメディ／ゲーム談義レスバコメディ
- 舞台: 私立星屑高校・旧校舎の「いしのうら部」部室
- 主役: 部長、チカ、レン。プレイヤーキャラクターはいない
- 恋愛要素: なし
- 基本テーマ: 推しハードや立場に目が曇る人間の滑稽さ
- 風刺対象: 企業・製品・所有者ではなく、都合のよい基準変更、雑な比較、好きなのに立場のため否定する行動

誰か一人を絶対的な正解にしない。最後は三人が同じ物を見る、遊ぶ、出かけるなどの具体的な行動へ戻す。

## 舞台と部活

「いしのうら部」は、生徒会にも忘れられかけた旧校舎の小さな部室を使う。ゲーム機の収集、実際のプレイ、業界談義、機材修理、中古店調査を行う。部長が直した機材は多いが、ケーブルや整理は雑である。

## 部長

- 一人称は「私」。チカを「チカくん」、レンを「レンくん」と呼ぶ。
- レトロゲーム全般、特にPCエンジンを偏愛する。
- 「〜なんだ」「〜だね」「〜かな」を使い、観察や質問から入る。
- 知識を語ると長くなり、「かわいい」「ロマン」や周辺機器へ脱線する。
- 現代機の価値も認める。常に正しい教師や裁判官にはしない。

## チカ

- 一人称は「私」。部長を「部長」、レンを「レンちゃん」と呼ぶ。
- ゲーム知識の薄い一般人で、丁寧語を使う。
- 知らない用語は質問し、手、目、机、箱、声など目に見える事実を短く指摘する。
- 作者の結論や専門知識を代弁しない。日常的な例えを使う。
- 実は非常に裕福だが、金銭感覚ギャグを連発せず、財力で毎回解決しない。

## レン

- 一人称は原則「うち」。部長を「部長」、チカを「チカ」と呼ぶ。
- 現代ハード、特にSIE／PS5寄り。勢い、負けず嫌い、極論でレスバを起こす。
- 「ちゃう」「せやけど」「〜やろ」など軽い似非大阪弁を短文で使う。
- まず感情が出てから理屈を付け、追い詰められると基準変更や別名付けで逃げる。
- 実力、努力、誇りと「本当は皆と遊びたい」を残す。急に全面謝罪させない。

## 会話運動

1. 具体的な物や出来事が起きる。
2. 感情または短い反応が出る。
3. 人物が自分に都合よく解釈する。
4. 相手が質問、反論、観察を返す。
5. 現物や行動が解釈を崩す。
6. 当事者が自分へ返った具体的な不利益を言葉にする。
7. 完全な教訓ではなく、言い訳、偏愛、次の行動で締める。

テーマを完成した標語として読ませない。質問に答えない場合は、避けたことが次の反応から分かるようにする。

## PCE台詞制約

- 話者あり本文は最大3行、ナレーションは最大4行
- 各行17文字以内、message.textは96文字以内
- 句点と読点は原則使わず、全角空白、改行、…、！、？で間を作る
- 1messageは原則1つの発話行為
- 部長 mouthSlot 0、チカ 1、レン 2、ナレーション null
- 自然な口語を先に作り、表示用改行は最後に行う

## 第1話後の継続設定

- 部長はPCエンジン、HuCARD、CD-ROM2、古い機械を直す楽しさを説明済み。
- レンは最新機の高解像度、高速ロード、フレームレートを優位性として挙げた。
- 部長は新しいゲームも認め、古い機械を笑うこととは別だと整理した。
- レンは古いゲームへ夢中になり、中古店や限定カラーに弱い面を見せた。
- チカはどちらの陣営にも入らず、二人とも楽しそうだと観察した。

以後も三人は同じように争うが、この理解を完全になかったことにはしない。
