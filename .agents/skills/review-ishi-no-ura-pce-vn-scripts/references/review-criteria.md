## 1. レビュー順

各話をscene配列順に読み、choiceでは両方のtargetを追ってから合流へ戻る。機械検査の警告を先に確認するが、警告のないmessageもすべて読む。

1. そのscene直前の出来事を一文で書く。
2. 各人物が今ほしい結果を確認する。
3. 各発話が何へ反応しているかを追う。
4. scene末尾から次scene冒頭への因果を確認する。
5. 全話を読んだ後に、口語、人物口調、重複を文単位で直す。
6. 最後にPCE改行とmetadataを検査する。

## 2. 問題分類

| category | 判定対象 |
| --- | --- |
| unnatural-japanese | 助詞、語順、書き言葉、口にしない表現 |
| abrupt-context | 前触れがない話題、反応先がない台詞、scene接続不足 |
| continuity | 過去話や同一話内の設定・行動との矛盾 |
| character-voice | 一人称、呼称、知識、目的、口調、人物入れ替わり |
| abstract | 現物より先に出る標語、評論、比喩、作者の結論 |
| redundancy | 無目的な言い換え、説明の再掲、同じボケの停滞 |
| factual-risk | 根拠のない価格、性能、企業方針、販売数などの断定 |
| speaker-metadata | speaker、mouthSlot、voiceの不一致 |
| pce-layout | 17文字、行数、96文字、改行位置 |
| structure | scene順、質問と答え、感情段階、分岐、合流の再構成 |

severityは、意味や人物像を誤解させるものをhigh、会話の流れを阻害するものをmedium、読み味や軽微な表示問題をlowとする。

## 3. 構成監査

- scene冒頭は直前の具体的な出来事がなくても言えてしまわないか。
- 直前の質問へ答えるか、答えたくない反応になっているか。
- 三人が作者の説明を順番に読む「並行独白」になっていないか。
- 感情が、驚き、否定、言い訳、沈黙を飛ばして反省や和解へ移っていないか。
- チカが知るはずのない仕様や業界知識を結論として語っていないか。
- 部長だけが毎回最終回答を授けていないか。
- レンの極論にも努力、欲望、遊びたい気持ちが残っているか。
- 分岐差分が片方だけ正解にならず、短く自然に合流するか。
- 現物、勝敗、買い物などが口論へ具体的な結果を返すか。
- タグのオチが直前の着地を壊すほど人物を退行させていないか。

構成変更が必要なら、まずscene単位の所見を書く。単語の言い換えだけで因果不足を隠さない。

## 4. 台詞監査

### 音読

- 「〜ということになる」「〜において」「〜であるため」の連続を避ける。
- 名詞を三つ以上つなげず、主張・理由・結論を一文へ詰めない。
- 誰が何を指すか、前後を読んでも不明な指示語を直す。
- PCE改行で助詞だけが次行へ送られていないか確認する。

### 反応

各台詞は、答える、否定する、聞き返す、具体化する、そらす、観察する、感情を示す、のどれかで直前へ接続する。説明より先に「えっ」「待って」「今の何や」などの必要な反応を置く。

### 人物

- 部長: 質問と具体例。正論にも偏愛と脱線を残す。
- チカ: 丁寧語、素朴な質問、見える物。抽象的な総括を減らす。
- レン: 感情が先、理屈が後。似非大阪弁は短く、全面降伏しない。

### 抽象から具体へ

「強さ」「価値」「経験」「本質」「正しさ」だけで話を進めない。目の前の得点、手、箱、画面、声、値札などへ置き換える。意味を残せる場合だけ短い抽象語を使う。

特に次はAI調の強い候補として前後を再確認する。

- 終幕でナレーターが一般論や禁止命令を連続して読み上げる。
- 「入口」「地図」「景色」「本来の役目」など、直前の物や動作を指さない比喩が続く。
- 「今日はそういう回」のように人物が作品構造を外側から説明する。
- チカが観察ではなく完成した倫理規則を断言する。
- 実在市場の売上や企業動向を、対象、期間、出典なしに権威として使う。

結論を消すだけでなく、紙へ書く、棚から出す、同じ画面を見る、次の対戦を選ぶなど、そのsceneで人物が取れる行動へ置き換える。

### 選択肢ラベル

- 全choiceラベルを本文と同様に音読し、脱字、助詞、人物の選択として自然かを確認する。
- ラベルと分岐冒頭の復唱に同じ誤字がないか確認する。
- ラベル修正はreplace-choice-labelと1始まりのchoiceNumberで追跡する。
## 5. 変更を抑える基準

- 意味が明確で人物らしい台詞を、単なる好みで均質な標準語へ直さない。
- レンの読みやすい方言、チカの少し独特な丁寧語、部長の脱線は欠点ではなく個性として残す。
- PCE制約に収まっている改行を、見た目だけの理由で大量変更しない。
- 事実確認できない箇所は断定へ書き換えず、factual-riskとして要確認にする。
- 台詞の追加は、反応や因果を補う最小限にする。

## 6. 完了判定

reviewSummary.coverageへ次を記録する。

- 読了したmessage数／総message数
- 読了したscene数／総scene数
- 読了したchoiceラベル数、追跡したchoice数と分岐target
- 機械検査warningの確認結果
- 未解決の事実確認、構成判断、音声再生成リスク

変更が0件でも、全項目を確認した根拠がなければSELF_REVIEWEDにしない。
