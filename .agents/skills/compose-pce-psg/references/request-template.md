# Composition Request

Collect these five items when they are material and not already supplied:

```text
用途・場面:
雰囲気を表す言葉を2～4個:
テンポ（BPMまたは遅い/普通/速い）:
長さと構成（例: 16小節、メロ8→サビ8）:
ループの有無:
```

Use these optional fields to improve targeting:

```text
曲名 / asset ID:
調・モード:
コード進行:
メロディの性格:
サビで変える要素:
欲しい編成:
打楽器の強さ:
避けたい要素:
出力先:
参考曲から借りたい抽象要素（テンポ・音色・リズム・展開）:
```

When unspecified, use 72 BPM, 4/4, 16 bars, A 8 bars to B 8 bars, C major for bright material, up to six channels, light noise percussion, and a seamless loop.

Recommended brief:

```text
放課後の部室で流す、のんき・温かい・少しコミカルなBGM。
72 BPM、4/4、16小節、メロ8小節→サビ8小節。
Cメジャーで、跳躍の少ない口ずさみやすい旋律。
サビでは1オクターブ上げ、対旋律とベースの刻みを増やす。
lead、柔らかいpad、8分音符arp、bass、軽いnoise drumsを使用。
最終G和音から先頭C和音へ自然につながるループ。
IDはclubroom_day。
```
